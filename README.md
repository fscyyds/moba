# MOBA 3v3 PC 端原型

按 3v3 双路 MOBA 搭建的服务端权威（Server Authoritative）原型。当前为 PC 网页版，使用键鼠操作，后续可迁移到 Unity/Godot 原生客户端。

## 核心特性

- **3v3 对战**：红蓝双方各 3 名玩家，满 6 人自动开局
- **双路兵线**：上路、下路自动出兵
- **经济系统**：自然增长（5金币/秒）+ 补刀收益 + 击杀助攻 + 推塔/野怪
- **等级成长**：升级提升属性，3级解锁大招（R）
- **大小龙 BUFF**：小龙加攻击力，大龙加移速/对塔伤害/金币收益
- **3 个差异化核心英雄**：
  - 狂战士：近战、移速最快、血量最厚
  - 奥术师：中距离技能爆发、身板脆
  - 神射手：最远射程、高攻速、脆皮
- **3 技能 + 1 大招**：Q/W/E/R，大招（R）需升到 3 级解锁
- **泉水与回城**：D 键回城，泉水内快速回血回蓝
- **死亡与复活**：死亡后显示复活倒计时，在泉水复活
- **PC 键鼠操作**：WASD / 鼠标右键移动，鼠标左键普攻，Q/W/E/R 朝鼠标释放技能，D 回城
- **简易草丛视野**：进入草丛后，敌方需靠近才能发现
- **法力值系统**：每个英雄有独立蓝量/回蓝，技能释放需消耗法力，蓝量不足时客户端提示“法力不足”
- **小兵仇恨机制**：英雄普攻敌方英雄时，目标附近 500 码内敌方小兵会切换仇恨攻击该英雄，持续 3 秒
- **打击感反馈**：受击单位闪白、飘字伤害数字（暴击金色大字）、击杀时屏幕震动、命中/技能/击杀/推塔音效
- **氛围音效**：Web Audio API 合成的背景音乐，以及可一键静音的音量控制
- **2D 伪深度渲染**：所有实体按 Y 轴排序绘制，Y 越大越靠前，产生前后遮挡；每个实体脚下绘制半透明阴影，增强站在地面上的立体感
- **顿帧（卡肉）**：击杀或暴击时客户端短暂冻结 50~100ms，大幅提升打击重量感
- **小地图**：右上角实时显示全局地图、队友/敌人/防御塔/野怪位置与摄像机视野框
- **非指向性技能**：奥术师 Q 改为向鼠标方向发射的 Skill Shot，需要预判走位
- **英雄碰撞体积**：服务端处理英雄互相推开与墙体滑动阻挡，支持卡位、挡技能
- **瓦片地图**：地图配置从 `server/map.json` 加载，客户端与服务端共用同一份地图数据，支持墙体障碍
- **开发者调试面板**：一键生成敌方 AI、立即复活、升级、加金币、刷新大小龙、立即结束对局；实时显示游戏时间、双方击杀、大小龙刷新倒计时
- **战后数据统计面板**：对局结束后展示每位英雄的 KDA、等级、金币、输出/承伤/治疗量，并绘制双方经济曲线
- **服务端权威**：所有战斗判定、伤害计算、状态同步在服务端运行

## 技术栈

- 服务端：Node.js + `ws` 库
- 客户端：HTML5 Canvas + WebSocket
- 同步：20 tick/s 状态广播

## 运行方式

### 1. 启动服务端

```bash
cd moba/server
npm install   # 首次运行
npm start
```

### 2. 打开客户端

浏览器访问：`http://localhost:8080`

### 3. 本地 3v3 测试

打开 6 个浏览器标签页，分别选择不同英雄加入对局。

### 4. 命令行机器人对战测试

```bash
cd moba/server
node test_bot.js        # 6 个 AI 自动打满一局，验证对局能否正常结束
node test_end_stats.js  # 快速验证战后统计面板数据下发
```

## 项目结构

```
moba/
├── server/
│   ├── server.js           # 3v3 游戏逻辑 + WebSocket 服务器
│   ├── test_bot.js         # 6 个 AI 自动对战测试
│   ├── test_end_stats.js   # 战后统计消息验证
│   ├── package.json
│   └── node_modules/
└── client/
    ├── index.html     # PC 端页面
    └── client.js      # Canvas 渲染 + 键鼠输入
```
