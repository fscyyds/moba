# MOBA 3v3 — 东方幻想风

3v3 双路 MOBA，服务端权威架构，网页 + Godot 双客户端。

## 快速开始

```bash
cd moba/server
npm install
npm start
# 浏览器打开 http://localhost:8080
```

或双击 `开始游戏.command` 一键启动。

## 核心特性

### 地图
- 10000×10000 像素，东方幻想手绘风格
- 三条兵线（上/中/下）连接双方基地
- 河道斜穿中央，带动态水纹效果
- 水晶光晕脉冲 + 泉水波动环 + 治愈粒子
- 野区散布古树、石块、灌木、水塘
- 地图边界悬崖迷雾渐变

### 英雄（3 个差异化角色）
| 英雄 | 定位 | 移速 | 普攻距离 |
|------|------|------|----------|
| 狂战士 | 近战坦克 | 360 | 120 |
| 奥术师 | 远程法师 | 350 | 450 |
| 神射手 | 远程ADC | 340 | 550 |

每英雄 3 技能 + 1 大招（3级解锁），含破甲/减速/护盾/定身/隐匿/击杀刷新等机制。

### 防御塔
- 四级塔：T1(400码)→T2(450码)→T3(500码)→水晶(800码)
- 逐塔击破：前一级未摧毁时下一级无敌
- 塔攻击力随时间成长 + 连续攻击伤害递增
- 无兵线保护：英雄打塔减伤90%
- 开局前4分钟打塔伤害减半
- 攻击范围可视化：敌方塔红色脉冲圈 + "!"告警，我方塔蓝色安全圈

### 小兵系统
- 首波10秒，每30秒一波
- 每波：2近战+3远程，每3波+1炮车
- 随时间成长（每3分钟全属性+10%）
- 炮车：远程450码，无兵时优先打塔
- 高地塔被破该路出超级兵
- 补刀+30%金币，漏刀获50%保底

### 野怪系统
| 类型 | 首次刷新 | 刷新间隔 |
|------|----------|----------|
| 小野营地(8个) | 30秒 | 70秒 |
| 红蓝Buff | 30秒 | 90秒 |
| 暴君(小龙) | 2分钟 | 2分钟 |
| 主宰(大龙) | 8分钟 | 3分钟 |

龙魂层数制（最多3层） + 主宰先锋替换兵线 + 10分钟进化。

### 经济系统
- 自然增长：5金币/秒
- 补刀：近战65 炮车120 英雄200+
- 团队分配：附近友军获50%额外金币
- 大龙BUFF：金币+30%

### 传送系统
- 4座对角传送阵，站立3秒触发
- 全球传送（T键，3级解锁）：4秒引导传送至己方塔/小兵

### 草丛视野
- 移动暴露（300码可见晃动），静止1秒完全隐身
- 19个草丛分布于转角、河道、传送阵、野区

## 技术栈

| 端 | 技术 |
|----|------|
| 服务端 | Node.js + WebSocket (ws) |
| 网页客户端 | HTML5 Canvas + WebSocket |
| Godot客户端 | Godot 4.2 + GDScript |
| 同步 | 20 tick/s 状态广播，服务端权威 |

## 项目结构

```
moba/
├── server/
│   ├── server.js         # 游戏逻辑 + WebSocket
│   ├── map.json          # 地图配置
│   ├── test_bot.js       # AI机器人测试
│   └── package.json
├── client/
│   ├── index.html        # 网页端
│   └── client.js         # Canvas渲染
├── moba-godot/
│   ├── project.godot     # Godot项目
│   ├── scenes/           # 场景文件
│   └── scripts/          # GDScript脚本
├── tools/
│   └── render_map.py     # 地图图片生成
└── 开始游戏.command       # macOS一键启动
```

## 操作方式

| 操作 | 网页版 | Godot版 |
|------|--------|---------|
| 移动 | WASD / 右键点击 | WASD |
| 普攻 | 鼠标左键 / J / 空格 | J / 空格 |
| 技能 | Q / W / E / R | Q / W / E / R |
| 回城 | D | D |
| 传送 | T（3级） | T |
| 选择英雄 | 菜单点击 | Q/W/E键 |
